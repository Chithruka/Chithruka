How KODEX connects to open catalogs, respects CORS rules, and unlocks MangaDex chapter images + Archive CBZ/EPUB streaming.

Live Integrated APIs

Active
  • PoetryDB (poetrydb.org) — Direct CORS-enabled REST API for classic English poetry & author anthologies.
  • Jikan v4 (api.jikan.moe) — Unofficial MyAnimeList API for manga discovery, ratings, demographics, and synopses.
  • MangaDex (api.mangadex.org) — Rich manga catalog, chapter lists, and page streaming (images load best with the included local proxy).
  • Gutendex (gutendex.com) — Project Gutenberg JSON catalog of 70,000+ public domain books.
  • Open Library (openlibrary.org) — Internet Archive's open book catalog, ISBN lookups, and cover art.
  • Internet Archive (archive.org) — Public domain Golden/Silver Age comics, vintage books, CBZ/EPUB metadata, and embedded BookReader.

Optional 1-Click Windows Proxy Server

Checking...

Browsers enforce CORS on external image/binary downloads (like MangaDex At-Home chapter images, raw Project Gutenberg .txt files, and Internet Archive .cbz/.epub binaries).

To enable seamless streaming for those external files on Windows without installing Node.js or Python, simply double-click start-server.bat (or run start-server.ps1) in this project folder and open http://localhost:8080.
